# Proyecto de Análisis de Vehículos

Este repositorio contiene el código y los archivos necesarios para el proyecto del Sprint 7 de TripleTen.

## Aplicación Web
Puedes acceder a la aplicación web interactiva desplegada en Render a través del siguiente enlace: 
https://proyectos-vehiculos.onrender.com

## Contenido del Repositorio
* **`app.py`**: Código fuente de la aplicación con Streamlit.
* **`vehicles_us.csv`**: Conjunto de datos utilizado para el análisis.
* **`requirements.txt`**: Dependencias de Python requeridas para ejecutar la aplicación.
* **`EDA.ipynb`**: Cuaderno con el análisis exploratorio de datos.
